# go-templ-mock-1

This is a mockup for testing Go with HTMX 4.0 <https://four.htmx.org/>, Templ for templating
and <https://github.com/axadrn/shadcn-templ> for design. 

## Claude instructions

Generate a simple Go web app that uses Templ, HTMX 4.0, TailwindCSS 4.3.

### HTMX 4.0

We are not really showcasing or testing any HTMX features in this mockup, but
this is a test for my next project that will have HTMX so we may as well include it here
<https://four.htmx.org/>

### Shadcn-templ

Use the latest BETA release: `v2.0.0-beta.15` (2026-10-22) <https://github.com/axadrn/shadcn-templ/releases>

### TailwindCSS

Use TailwindCSS 4.3.

I have the 4.3.3 version of the tailwind CLI installed on my Mac:

```bash
❯ tailwindcss --version
≈ tailwindcss v4.3.3
``` 

### go-task

Create a `Taskfile.yaml` to run the project's build and everything else
